# E1 · OTA 在线升级

板子连上 Wi-Fi 后开一个网页，浏览器选 `.bin` 文件上传，走 `Update.h` 写进 ota 备用分区，校验通过自动重启进新固件——全程不插 USB。屏幕实时显示写入进度百分比。

⚠️ 本课代码未经真机验证

## 操作

```sh
uv run pio run -d labs/sys-lab-e1 -t upload -t monitor
```

（第一次还是要 USB 烧"OTA 引导"固件，之后就再也不用了。）

1. 板子连上 Wi-Fi 后，屏幕显示 IP 地址。
2. 浏览器打开 `http://<板子IP>/`。
3. 选择固件文件上传：

```sh
# 新固件就是普通编译产物（改改代码重新编译即可）：
labs/sys-lab-e1/.pio/build/wifi-lab-e1/firmware.bin
```

> 注意路径里的 `wifi-lab-e1` 是环境名，OTA 的 bin 路径跟它走。

## 预期现象

- 上传时屏上进度条从 0% 走到 100%，串口每块打印已写入字节数。
- 100% 后板子自动重启，新固件的编译时间戳出现在页面标题（`当前固件: E1 <日期时间>`），用来确认升级真的生效了。
- 升级失败（传错文件/断网）屏幕红字报错，板子仍跑旧固件——OTA 不刷当前运行分区，不会变砖。

## 排错

- **上传成功但没变化**：选错文件（传了 `firmware.elf` 或别的工程的 bin）；确认文件名是 `firmware.bin`。
- **进度卡住/失败**：板子和电脑必须在同一 Wi-Fi；别用手机热点省流量模式。
- **`begin 失败`**：分区表没有 ota 分区才会出——本课用默认 16MB 布局（app0/app1 各 6.25MB），别改 `board_build.partitions`。
- **配网**：NVS 没凭证会自动开热点 `esp32-ota-setup` 走 portal，同 W2 流程。
