# S1 水平仪

⚠️ 本课代码未经真机验证（寄存器配置来自公开数据手册与同类工程，编译通过但未上板跑过）。

一句话：用 I2C 读 QMI8658 姿态传感器的加速度计，在屏幕上画一个气泡水平仪——板子怎么斜，气泡就往翘起的那一侧跑，完全放平时气泡变绿。

## 操作

```bash
cd ~/code/esp-labs-lichuang
uv run pio run -d labs/sensor-lab-s1          # 编译
uv run pio run -d labs/sensor-lab-s1 -t upload  # 烧录
uv run pio device monitor -d labs/sensor-lab-s1 # 看串口（X/Y/Z 加速度）
```

## 预期现象

1. 上电后串口先打印 `WHO_AM_I=0xFD OK`（芯片自报家门成功）。
2. 屏幕出现一个大圆环 + 十字线，中间一颗彩色气泡。
3. 平放桌面：气泡居中、变**绿**（|水平分量| < 0.08g）。
4. 抬起一侧：气泡向翘起侧移动，微微倾斜变**黄**，斜得厉害变**红**并被限制在环内。
5. 串口每 200ms 打印一行 `X=+0.00 g  Y=+0.00 g  Z=+1.00 g`（平放时 Z≈±1g）。
6. 左上角显示实时数值读数。

## 排错

| 现象 | 原因 / 办法 |
| --- | --- |
| `WHO_AM_I` 读失败 / 全 0xFF | I2C 总线问题：确认 `Wire.begin(1, 2)` 已执行；用 05-i2c-scan 扫一遍，QMI8658 应在 0x6A |
| WHO_AM_I 值不是 0xFD | 芯片型号不对或寄存器布局不符（部分批次为 QMI8658C，WHO_AM_I 同为 0xFD） |
| 屏全黑 | IO 扩展器没初始化：`initIoExpander()` 必须在 `tft.init()` 之前跑（它负责拉低屏 CS） |
| 气泡方向和倾斜方向相反 | 把 `drawLevel()` 里 `a.x`/`a.y` 前的负号去掉（传感器贴片方向差异） |
| 读数不动 | 检查 CTRL7 是否写入成功（返回 false 说明 I2C NACK） |

## 知识点

- **WHO_AM_I 先行**：地址扫到 ≠ 芯片能用，先读 ID 寄存器再配置。
- **三步配置法**：CTRL1（接口/地址自增）→ CTRL2（量程 ±4g / 输出速率）→ CTRL7（使能加速度计）。
- **原始数据换算**：±4g 量程 = 8192 LSB/g，16 位小端直接拼，除一下就是 g。
- **局部刷新**：只擦上一帧气泡的小圆块，不全屏重画，不闪烁。
