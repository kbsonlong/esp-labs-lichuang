# E4 · 配置系统

Preferences 结构化配置 + 网页表单：城市坐标（纬/经）、刷新间隔、主题色（RGB565）存 NVS，浏览器打开 `/config` 表单修改（校验通过才落盘），屏上实时显示当前配置；长按 BOOT 3 秒恢复出厂（只擦配置，Wi-Fi 凭证保留）。

⚠️ 本课代码未经真机验证

## 操作

```sh
uv run pio run -d labs/sys-lab-e4 -t upload -t monitor
```

1. 无 Wi-Fi 凭证时先进配网（热点 `esp32-config-setup`，流程同 W2）。
2. 连上网后屏显当前配置和 IP；浏览器打开 `http://<板子IP>/config`。
3. 改数值保存；故意填个纬度 999 提交试试——校验会拒绝并提示，flash 不受影响。

## 预期现象

- 屏幕显示纬经度、刷新间隔、主题色色块（保存后立刻刷新）。
- 非法输入返回 400 + 错误提示，配置保持原值。
- 长按 BOOT 3 秒：屏幕「恢复出厂...」，重启后配置回默认（lat 23.13 / lon 113.26 / 600s / 青色 0x07FF），**Wi-Fi 不用重配**（配置和凭证是两个命名空间）。
- 断电重启，配置还在（NVS 掉电不丢）。

## 排错

- **保存成功但重启后丢失**：确认 `saveConfig()` 走的是 `prefs.begin(kConfigNs, false)`——只读模式（第二个参数 true）写入会静默失败。
- **恢复出厂连 Wi-Fi 也忘了**：检查是不是 `prefs.clear()` 开错了命名空间，只能 clear `kConfigNs`，绝不能动 `kWifiNs`。
- **页面打不开**：确认连的是板子所在同一 Wi-Fi，地址用屏显的 IP。
- **表单数字格式**：`toFloat()` 解析失败返回 0，会被范围校验拦下（纬度 0 是合法值，但不会误存垃圾数据）。
