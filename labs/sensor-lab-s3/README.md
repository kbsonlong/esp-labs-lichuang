# S3 滚动小球

⚠️ 本课代码未经真机验证（QMI8658/FT6336 寄存器细节同 S1/S2，来自公开数据手册，编译通过但未上板跑过）。

一句话：S1+S2 的合体——倾斜板子控制小球滚向低处，手指点哪球就搬到哪重新落下，60Hz 固定步进物理循环让弹跳节奏稳定。

## 操作

```bash
cd ~/code/esp-labs-lichuang
uv run pio run -d labs/sensor-lab-s3          # 编译
uv run pio run -d labs/sensor-lab-s3 -t upload  # 烧录
uv run pio device monitor -d labs/sensor-lab-s3 # 看串口日志
```

## 预期现象

1. 串口先打印 `WHO_AM_I=0xFD OK` 和 `[FT6336] 在线`。
2. 屏幕顶部标题栏 `S3 tilt ball | tap=move ball | BOOT=reset`，中间一颗橙色小球。
3. 平放：球静止。
4. 倾斜板子：球沿倾斜方向加速滚动，撞到屏幕边缘反弹（保留 80% 速度），微微倾斜时缓慢滚动。
5. 手指点屏幕任意位置：球瞬移到点击处、速度清零，从那里重新受重力落下。
6. 按 BOOT 键：球回到屏幕中心。

## 排错

| 现象 | 原因 / 办法 |
| --- | --- |
| 屏显示 `QMI8658 未就绪` | WHO_AM_I 校验失败：用 05-i2c-scan 确认 0x6A 在线 |
| 球滚的方向不对 | 加速度轴 -> 屏幕轴映射的正负号问题：调 `stepPhysics()` 里 `in.ax`/`in.ay` 的符号（代码有 UNVERIFIED 注释） |
| 点击位置和球出现位置对不上 | 触摸坐标映射方向问题：调 `readInput()` 里 `tapX`/`tapY` 换算（同 S2，四种组合） |
| 球穿墙/抖动 | 固定步进保护被触发（罕见）：确认 loop 里的补步上限没被长时间阻塞打破 |
| 弹跳太弹/太闷 | 调 `kRestitution`（0.80）；滚动太滑/太涩调 `kFriction`（0.995） |

## 知识点

- **固定步进物理**：物理以固定 dt=1/60s 推进，`micros()` 差值累计到 16667us 才走一步；渲染帧率波动不影响物理行为。累计上限 100ms 防止"时间债"滚雪球。
- **三层架构**：`readInput()`（只读传感器）/ `stepPhysics(dt)`（只改状态）/ `render()`（只画屏幕）——每层单独可测，换传感器或换渲染互不影响。
- **墙壁碰撞**：位置钳位 + 速度反向乘 restitution，一行一个轴。
- **传感器即手柄**：加速度计水平分量（单位 g）直接乘一个手感系数当屏幕重力。
