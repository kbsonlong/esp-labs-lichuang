# S2 触摸画板

⚠️ 本课代码未经真机验证（寄存器协议来自 FocalTech 公开数据手册，编译通过但未上板跑过）。

一句话：I2C 轮询 FT6336 触摸控制器，把手指在屏上的滑动画成彩虹色的线条，抬手断笔，BOOT 键清屏。

## 操作

```bash
cd ~/code/esp-labs-lichuang
uv run pio run -d labs/sensor-lab-s2          # 编译
uv run pio run -d labs/sensor-lab-s2 -t upload  # 烧录
uv run pio device monitor -d labs/sensor-lab-s2 # 看串口日志
```

## 预期现象

1. 上电后串口打印 `[FT6336] 在线，TD_STATUS=0x…`（地址 0x38 有应答）。
2. 屏幕顶部有一行灰色标题栏 `S2 touch paint | BOOT=clear`。
3. 手指按住屏幕拖动：画出彩虹渐变的粗线条（色相随笔画长度循环）。
4. 抬手后再落笔：从新位置重新起笔，不会出现横跨屏幕的直线。
5. 按 BOOT 键：清屏回到黑底。
6. 若触摸芯片不在：屏幕显示 `FT6336 not found`，串口有对应提示。

## 排错

| 现象 | 原因 / 办法 |
| --- | --- |
| `FT6336 not found` | 用 05-i2c-scan 确认 0x38 在线；检查 `Wire.begin(1, 2)` |
| 画的线方向不对（上下颠倒/左右颠倒/轴反了） | 触摸面板安装方向与代码假设不符：改 `readTouch()` 里 `sx`/`sy` 的换轴或翻转（代码注释给了四种组合） |
| 线条抖动/毛刺 | 轮询太快读到重复数据：可加"新点与旧点距离 < 2px 不画"的过滤 |
| 点了没反应 | 触点数寄存器 0x02 读到 0：FT6336 上电默认工作模式即正常，检查读数返回值 |

## 知识点

- **轮询式触摸**：FT6336 不接 INT 中断也能用——周期读 0x02（触点数，bit[3:0]，>2 视为异常丢弃），>0 再读 0x03-0x06。
- **12 位坐标拆装**：X = XH 低 4 位 << 8 | XL；Y 同理（YH 低 4 位是坐标，高 4 位是触点 ID）。
- **坐标变换**：面板竖屏安装（234x179），屏幕横屏 320x240，映射 = 90° 换轴 × 缩放（±方向翻转）。
- **断笔状态机**：`last.pressed` 就是一个两态状态机——落笔连线 / 抬手清空，漏了它必有跨屏直线。
