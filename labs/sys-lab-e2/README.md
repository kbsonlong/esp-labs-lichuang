# E2 · 深度睡眠

深度睡眠演示：定时器每 10 秒自动唤醒 + BOOT 键（GPIO0）ext0 随时唤醒；`RTC_DATA_ATTR` 变量跨睡眠统计唤醒次数，串口打印唤醒原因和次数，进睡前 LED 呼吸 3 秒。

⚠️ 本课代码未经真机验证

## 操作

```sh
uv run pio run -d labs/sys-lab-e2 -t upload -t monitor
```

烧录后什么都不用做，板子自己循环「醒 → 呼吸灯 → 报数 → 睡 10 秒」。

## ⚠️ 深度睡眠后 USB 串口会断，重新烧录需按住 BOOT 插 USB

深度睡眠会断开 USB-Serial-JTAG：串口监视器掉线是正常的，不是板子坏了。想重新烧录：**按住 BOOT 键插 USB**，板子进烧录模式后再执行 upload。

## 预期现象

- 上电第一次醒来：`[唤醒] 原因: 上电/复位（不是从深睡醒来），第 1 次`。
- 之后每 10 秒：`原因: 定时器到点`，次数 +1（RTC 内存变量跨睡眠存活）。
- 每轮入睡 LED 呼吸 3 秒（暗→亮→暗）。
- 睡眠期间按 BOOT 键：`原因: BOOT 键按下（ext0）`，并给 5 秒缓冲重连串口。
- 电流表（如果你有）能看运行 ~几十 mA → 深睡 ~几 mA 的跳水。

## 排错

- **串口断开**：见上方加粗提示；唤醒后板子会重新枚举 USB，监视器重开即可。
- **次数每次都从 1 开始**：说明 `RTC_DATA_ATTR` 没生效或板子被复位（按了 RST 键 = 掉电重启，RTC 内存清零）。
- **BOOT 键唤醒不响应**：ext0 用的是 GPIO0 电平触发，按住再插电不叫"唤醒"，要在深睡中**新按下**才触发。
- **烧不进去**：板子在深睡循环里，按住 BOOT 插 USB 强制进烧录模式。
