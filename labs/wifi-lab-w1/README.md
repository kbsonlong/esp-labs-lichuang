# W1 · 连网与时钟

无凭证时自动开热点进**配网模式**；配网成功后屏幕变实时时钟面板（日期 + 大字时间 + RSSI 信号条）。详见 docs/course.md 的 W1 章节。

## 完整操作

```sh
uv run pio run -d labs/wifi-lab-w1 -t upload -t monitor
```

首次使用（无需改代码）：

1. 手机连热点 **esp32-clock-setup**（无密码）
2. 浏览器打开 **192.168.4.1**（多数手机连上会自动弹出）
3. 选择你家 Wi-Fi、输密码、保存 → 设备自动重启连网
4. 屏幕变时钟面板；串口每秒同步打印时间与信号强度

换 Wi-Fi：长按 BOOT 键 3 秒，清除凭证重启回配网模式。
