## P1 · 桌面信息站

**一句话**：放在桌上的常驻小屏幕——时钟、天气、坐姿提醒三页面轮播，网页改配置。

**功能需求**

1. 三页面每 15 秒自动轮播：时钟页（W1）/ 天气页（W2）/ 坐姿页（S1）
2. 坐姿检测：QMI8658 检测板子（显示器旁的支架上）俯仰角持续 >20° 超过 10 分钟 → 屏幕变红 + 蜂鸣提示（可选 A1 音频）
3. 网页配置（E4）：城市坐标、轮播间隔、坐姿阈值、主题色——表单修改，存 NVS，重启生效
4. 长按 BOOT 3 秒恢复出厂

**边界**：不需要电池/外壳；断网时天气页显示缓存 + 灰色标记。

**验收清单**

- [ ] 三页面轮播流畅，无白屏闪烁
- [ ] 拔网线 10 分钟，天气页显示缓存并标注"离线"，恢复网络后自动刷新
- [ ] 坐姿提醒按阈值触发，阈值网页可调
- [ ] 所有配置断电保存；恢复出厂后回配网模式

**综合课程**：W1、W2、S1、E4（+A1 可选）

## P2 · 无线相机

**一句话**：能挂墙上的小监控——实时画面、手机观看、OTA 远程升级、断网自愈。

**功能需求**

1. 上电自动连网（NVS），失败进配网模式（全套 W1 流程）
2. 手机浏览器打开设备 IP 看实时 MJPEG 流（≥8fps）
3. 摄像头任务独立运行，Web 任务重启（浏览器断开/刷新）不影响采集
4. OTA：浏览器上传 .bin 升级固件，升级过程屏显进度，失败自动回滚到旧版
5. Wi-Fi 掉线自动重连，重连期间采集任务不停

**边界**：单客户端推流即可（双并发为加分项）；不需要移动侦测/录像存储。

**验收清单**

- [ ] 上电到可观看 ≤30 秒（含连网）
- [ ] 连续运行 2 小时无内存泄漏（heap 稳定）、无重启
- [ ] OTA 升级到新版本成功，且故意传一个坏 .bin 时设备保持旧版可用
- [ ] 重启路由器后 60 秒内自动恢复推流

**综合课程**：C1、C2、W1、E1

## P3 · 桌面小游戏机「重力球」

**一句话**：倾斜板子控制小球滚动的避障游戏，带音效和手机排行榜。

**功能需求**

1. 游戏玩法：S3 的物理小球 + 随机生成的障碍洞；球掉洞 = 扣一条命，三条命结束
2. 姿态控制（S1）：倾斜方向即重力方向
3. 音效（A1/A2）：碰撞"叮"、掉洞"噗咚"、开局旋律（预生成 PCM 数组存 flash）
4. 排行榜（W2/W3）：游戏结束输入（触摸软键盘选字母）成绩，POST 到家里某服务或局域网网页展示
5. 触摸点击开始/重开

**边界**：一屏一关卡（滚动前进制可做加分项）；音效用预生成数组，不要求实时合成音乐。

**验收清单**

- [ ] 帧率稳定 ≥30fps，物理步进与渲染解耦
- [ ] 全流程可玩：开始 → 游玩 → 死亡 → 输入名字 → 排行榜可见
- [ ] 音效与画面事件同步，无爆音
- [ ] 代码分层清晰：input / physics / render / audio / net 互不掺和（这是本项目的隐藏验收项）

**综合课程**：S1、S2、S3、A1、A2、W2/W3
